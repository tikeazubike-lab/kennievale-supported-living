# kennievale-supported-living

Design Direction: Premium Editorial Website

Use the website at https://www.signature-care-homes.co.uk/ as a visual and UX reference only.

The objective is NOT to recreate, clone, or closely reproduce the Signature Care Homes website.

Instead, analyse the reference to understand the design principles that create its premium, elegant, warm and sophisticated character, then create a new and clearly differentiated website design that applies those principles to a new brand.

1. Reference analysis

Use the reference website to understand:

overall visual hierarchy

editorial layout structure

spacing and whitespace

proportions

typography hierarchy

image scale and cropping

section rhythm

navigation behaviour

CTA prominence

use of large headlines

relationship between imagery and text

premium/luxury visual language

balance between warmth and sophistication

storytelling structure

responsive behaviour

The reference should be treated as a design benchmark, not a template.

The finished design must be immediately distinguishable from the reference.

2. Desired brand feeling

The new website should feel:

premium

sophisticated

warm

human

confident

calm

contemporary

editorial

aspirational

trustworthy

highly considered

Avoid making it feel:

clinical

institutional

generic corporate

overly technological

template-based

excessively minimalist

like a conventional healthcare website

The emotional impression should be closer to a combination of:

luxury hospitality + premium residential property + editorial lifestyle brand + trusted professional service.

3. Layout direction

Use an editorial, image-led layout system.

Prioritise:

generous whitespace

large visual compositions

strong vertical rhythm

large display typography

short, intentional text blocks

asymmetric compositions where appropriate

overlapping or offset elements where they improve the composition

varied image ratios

full-width imagery in selected sections

deliberate transitions between light and dark sections

strong alignment and grid discipline underneath the apparent asymmetry

Do not make every section look like a standard three-column card grid.

The page should feel art-directed.

Use a consistent underlying grid but allow elements to break the grid selectively for visual interest.

4. Typography

Create a sophisticated editorial typography system.

Use two complementary type families:

Display type

Use an elegant contemporary serif for major headlines.

It should feel:

refined

editorial

premium

calm

sophisticated

spacious

Use it for:

hero headlines

major section headlines

selected pull quotes

important statements

Supporting type

Use a clean contemporary sans-serif for:

navigation

body copy

metadata

buttons

labels

supporting headings

Use restrained font weights.

Avoid excessive bold typography.

Create strong contrast through:

scale

whitespace

weight

serif/sans pairing

uppercase labels

occasional italic emphasis

Do NOT attempt to copy Signature's exact font treatment.

The new typography should feel related in quality but clearly belong to a different brand.

5. Typography scale

Create a responsive type system approximately along these lines:

Eyebrow:
12–14px, uppercase, increased letter spacing

Navigation:
14–16px

Body:
17–19px desktop with comfortable line height

Small supporting text:
14–16px

Section headline:
48–72px desktop

Hero headline:
72–110px desktop depending on viewport

Mobile typography should scale intelligently rather than simply shrinking desktop values.

Prioritise readability and elegant line breaks.

Hero headlines should generally occupy no more than approximately 2–4 lines.

6. Imagery direction

Photography is a major part of the design.

Use an editorial lifestyle photography approach rather than generic corporate stock photography.

Preferred image categories:

beautiful architecture

sophisticated interiors

people in natural environments

candid human interaction

lifestyle moments

dining

hospitality

gardens and landscape

close-up material/detail photography

environmental portraits

natural daylight

moments that communicate warmth and dignity

Avoid:

obvious stock photography

staged medical scenes

generic healthcare imagery

overly posed portraits

excessive smiling-at-camera photography

clinical hospital environments

Images should feel:

cinematic

authentic

warm

sophisticated

naturally lit

editorial

emotionally subtle

Use varied image compositions rather than putting every image into identical cards.

Include:

full-bleed images

tall portrait crops

wide landscape crops

detail crops

editorial image/text pairings

Images should have enough negative space where text may need to overlay them.

7. Colour system

Do not copy the reference site's exact colours.

Instead, create an original premium palette inspired by the emotional qualities of the reference.

Explore a palette based around:

warm ivory

soft stone

muted neutral tones

deep charcoal

one distinctive sophisticated accent colour

The palette should feel warm and luxurious rather than bright and corporate.

Use colour sparingly.

Large areas of neutral space should be allowed to exist without decoration.

Create a strong contrast between:

light editorial sections

darker immersive sections

photography-led sections

The final palette must feel like its own brand.

8. Navigation

Create a restrained premium navigation system.

It should be significantly simpler visually than a typical corporate website.

Suggested information architecture:

About

Services

Locations

Experience

Insights

Contact

Include one visually prominent primary CTA.

The navigation should feel:

calm

spacious

confident

premium

easy to understand

Avoid reproducing the exact Signature navigation structure.

9. Hero section

Create a highly polished hero.

The hero should immediately communicate the brand's positioning.

Use:

a large editorial image or cinematic image composition

an oversized headline

a concise supporting statement

one primary CTA

optionally one secondary low-emphasis action

The hero should feel immersive rather than like a conventional corporate banner.

Experiment with an image composition where the photography occupies a substantial portion of the viewport and typography creates a strong visual counterweight.

Do not reproduce Signature's exact hero composition.

10. Homepage structure

Create the homepage with the following general storytelling rhythm:

Section 1 — Hero

Large image + powerful headline + concise positioning statement + primary CTA.

Section 2 — Brand statement

A substantial editorial statement explaining what makes the new organisation different.

Use large typography and generous whitespace.

Section 3 — Core proposition

Introduce 3–4 major differentiators.

Do NOT automatically use standard cards.

Explore an editorial composition where typography and imagery work together.

Section 4 — Experience

Use a large photography-led section to communicate the experience of the brand.

Allow imagery to dominate.

Section 5 — Services

Present the major services/offers clearly but elegantly.

Use a structured layout, but avoid generic SaaS-style cards.

Section 6 — Locations / Properties / Places

Create an image-led discovery section.

Prioritise photography, location and atmosphere.

Section 7 — Human stories / testimonials

Use authentic-feeling testimonials or stories.

Give the quotation substantial visual importance.

Avoid making testimonials look like generic review widgets.

Section 8 — Editorial / Insights

Introduce articles, stories or resources using an editorial magazine-like treatment.

Section 9 — Strong CTA

Create a large, emotionally confident final CTA.

Section 10 — Footer

Create a sophisticated, spacious footer with clear navigation and contact information.

11. Components

Create a reusable component system for:

navigation

buttons

image blocks

editorial image/text sections

service listings

location cards

testimonials

article cards

section labels

forms

footer

CTA panels

Components should feel bespoke rather than like standard UI-library components.

Use subtle interaction states.

Avoid excessive rounded cards, gradients, shadows and decorative UI.

12. Spacing

Use generous spacing throughout.

The design should never feel crowded.

Use a consistent spacing system but allow large editorial sections to breathe.

Prefer:

large vertical margins

generous text/image separation

wide page margins

comfortable line lengths

substantial section padding

Whitespace is an intentional design element.

Do not fill empty areas merely because space is available.

13. Grid

Use a sophisticated responsive grid.

Desktop:

approximately 12 columns

generous outer margins

consistent gutters

Tablet:

adapt to approximately 8 columns

Mobile:

4-column or appropriate responsive grid

Maintain strong alignment between:

headlines

body copy

images

CTAs

section boundaries

Some images or decorative elements may intentionally break the grid.

14. Responsive design

Design desktop, tablet and mobile states.

Do not simply stack every desktop section vertically.

For mobile:

preserve editorial hierarchy

maintain generous whitespace

maintain image impact

simplify navigation

prioritise the primary CTA

create elegant image cropping

ensure typography remains sophisticated

avoid excessive text density

The mobile version should feel deliberately designed rather than like a compressed desktop website.

15. Creative differentiation

This is critical.

The result must NOT look like a Signature Care Homes clone.

Do not copy:

logo

brand name

exact colours

exact typography

exact navigation

exact wording

exact image selection

exact section ordering

exact card designs

exact hero composition

exact CTA design

exact page layouts

Instead, preserve only the underlying principles:

premium + editorial + warm + sophisticated + image-led + generous whitespace + strong typography + human storytelling.

Introduce enough new design decisions that the finished website could plausibly belong to an entirely different premium brand.

16. Generate three design directions

Create three distinctly different visual directions based on this brief.

Direction A — Refined Editorial

The closest to the reference's level of luxury and sophistication.

Emphasis:

elegant typography

large photography

generous whitespace

restrained colour

classic editorial composition

Direction B — Contemporary Luxury

Push the design toward a more modern, architectural aesthetic.

Emphasis:

stronger grid

more dramatic typography

larger image crops

more asymmetry

stronger contrast

more contemporary component design

Direction C — Warm Human Luxury

Make the design more emotionally expressive and human.

Emphasis:

warmer imagery

softer typography

intimate photography

storytelling

tactile visual details

stronger sense of community and belonging

All three directions must remain premium.

Do not simply change colours between directions. Change the actual visual language and composition.

17. Final design test

Before finalising, evaluate the design against this question:

"If the Signature Care Homes website disappeared, would this design still look like it belongs to its own brand?"

The answer must be YES.

The website should communicate the same level of sophistication and quality as the reference while being visually and structurally distinguishable.

Prioritise originality, strong art direction, typography, photography, whitespace and visual hierarchy over simply matching the reference.

Generate the initial homepage concepts first before expanding the entire site.
